# Task 2 - Tic-Tac-Toe AI

## Description

This project is an AI-powered Tic-Tac-Toe game developed using Python and Pygame as part of the CodSoft Artificial Intelligence Internship.

The AI opponent uses the Minimax Algorithm with Alpha-Beta Pruning to evaluate possible game states and make optimal decisions, making it impossible to defeat.

## Features

- Interactive graphical user interface built with Pygame
- Unbeatable AI opponent using Minimax
- Alpha-Beta Pruning optimization
- Hover effects for better user experience
- Win and draw detection
- Restart functionality

## Concepts Used

- Minimax Algorithm
- Alpha-Beta Pruning
- Recursion
- Backtracking
- Game Trees
- Adversarial Search

## Technologies Used

- Python
- Pygame

## Installation

```bash
pip install pygame

python tic_tac_toe.py
```

## Outcome

This project helped in understanding how AI agents make decisions by exploring future game states and selecting the most optimal move.
